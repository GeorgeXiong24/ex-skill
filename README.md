# ex-skill

ex-skill is a skill that allows users to upload evidence and data of his/her past with ex-girlfriend or ex-boyfriend, then the skill will help analyze the user's ex-girlfriend or ex-boyfriend to intimate his/her ways of speaking, tone of conversation, memory points, personal traits, and more.

Users can upload text-based data including conversations, personal description of her/his personality or other ways, so this skill can help you analyze and summarize her/his top traits into a .json file, AI may call it later on to create a skill that acts as complete what is shown in the .json file, which acts as a AI companion for the user's ex to provide therapeutic conversations with users, reminisce about shared memories, and experience closure through friendly, supportive dialogue.
